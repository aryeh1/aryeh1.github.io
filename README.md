# aryehlopian.com

Minimal landing page for Aryeh Lopian.

**Live:** [aryehlopian.com](https://aryehlopian.com)

## Setup

```bash
npm install
npm run dev
```

## Stack

React 19 + TypeScript + Vite + Tailwind

## Structure

This repo contains only the public landing page. The full application (Lab, projects, tools) is in a separate private repo at [lab.aryehlopian.com](https://lab.aryehlopian.com).
